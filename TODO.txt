OpenPHIGS: missing C and FORTRAN bindings
=========================================

Compared against the PHIGS (ISO/IEC 9592-1) and PHIGS PLUS (ISO/IEC 9592-4)
function lists. The ISO documents were not available; the reference was
assembled from public sources:
  - X Consortium PEX-SI headers (C names, incl. PHIGS PLUS):
    https://www.x.org/archive/unsupported/lib/PHIGS/include/
  - IBM graPHIGS ISO PHIGS Subroutine Reference (C and ISO FORTRAN names):
    http://ps-2.kev009.com/tl/techlib/manuals/adoclib/libs/phigsiso/toc.htm
No public list of PHIGS PLUS FORTRAN names was found, so for PHIGS PLUS
only the C binding is compared. A '-' means the name is not known.
The same information is in src/docs/bindings_status.dox (man page
bindings_status(3)).

Summary
-------

              functions  C implemented  FORTRAN implemented
  ----------  ---------  -------------  --------------------
  PHIGS       326        206            132
  PHIGS PLUS  75         21             13 (OpenPHIGS names)
